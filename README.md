## 📌 About

Hi, I'm **AditSubarjo**, the creator and developer behind **Niclo Project**.

Niclo Project is an independent game modification and development project focused on expanding and experimenting with the possibilities of **GTA San Andreas Multiplayer (SA-MP)**.

The project previously explored the Roblox platform, particularly **Violence District**. However, its development direction has since shifted towards SA-MP.

Currently, Niclo Project is exclusively focused on **internal development using MoonLoader and Lua scripts**.

## 🛠️ Features

### 🟢 Available Features

#### ⚡ Faster C-Bug
Designed to make C-Bug and Litefoot execution easier and more consistent.

This feature takes inspiration from **FasterCbug by opcodeX**, with ideas and code adapted from the original application.

#### 👊 Heavy Fist
Originally developed as an ASI script and later converted into Lua.

Heavy Fist is designed to improve Litefoot execution, making movement smoother and more consistent.

#### 💤 Anti-AFK
Allows players to switch between game windows without immediately triggering inactivity detection.

Useful for players who want to leave the game running while using other applications.

**⚠️ Current Limitation:** Servers with movement-based AFK detection may still flag players who remain stationary for an extended period, such as five minutes or longer. Improvements are planned.

#### 🎭 Skin Changer
A straightforward skin-changing feature that allows players to customize their in-game character appearance.

#### 🔫 Full Skill Gun
Automatically sets supported weapon skills to their maximum level, eliminating the need for manual weapon-skill training.

Designed with servers such as **State Side Roleplay**, **JogjaGamers Reality Project (JGRP)**, and other old-school SA-MP servers in mind.

Maximum weapon skill provides access to higher weapon proficiency, including the handling and movement associated with Hitman-level skills.
